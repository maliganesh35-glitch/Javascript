JavaScript Keywords--
==============================================================
Keywords are part of the language grammar. They tell the JavaScript engine what structure or action to expect.

Examples of always reserved keywords:
if, else, for, while, function, return, class, const, let, switch, case, break, continue, try, catch, throw.

Strict-mode reserved words:
implements, interface, package, private, protected, public, static.

Future reserved words:
enum.

Contextual keywords (special only in certain positions):
async, await, of, get, set.

Reserved literals:
true, false, null.
